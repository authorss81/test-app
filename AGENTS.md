# Project Memory — Test App

This file is the source of truth for test data rules. Always refer to this when adding/editing tests.

## Test types & totals

| Test type                                  | Total marks | Questions/subject |
|--------------------------------------------|-------------|-------------------|
| AIATS Paper-1, Paper-2 (JEE Advanced)      | 360         | 30 (120 each)     |
| AIATS (JEE Main) — UT-01 (JEE Main)        | 300         | 25 (100 each)     |
| Practice Test, Term Exam                   | 360         | 30 (120 each)     |

Subject split is always: Physics, Chemistry, Mathematics (each equal share of total).

## Marks formula

- Correct: full marks for the question
- **Incorrect = -5** marks per wrong answer
- **Unattempted = -4** marks per unattempted question
- For most tests, only 1 wrong answer and 0 unattempted (so score = total - 5)

## Wrong-answer subject rules

- **Math has ZERO wrongs** (always 120/120 or 100/100)
- Wrongs only appear in **Chemistry** or **Physics**
- Per test: max 1 wrong, 0 unattempted (exception: legacy entries may differ but new entries must follow this)

## Rank rules

- **AIR (All India Rank):** 1–3 only
  - Full marks → AIR 1
  - 1 wrong   → AIR 2 or 3 (usually 2)
- **State Rank:** 1 or 2 only
  - Full marks → state 1
  - 1 wrong   → state 2 (occasionally state 1 if super close)
- **Batch Rank:** always 1
- **Branch Rank:** always 1

## Latest-two-tests special rule

The two newest tests (last in the list, shown at the bottom of the **newest-first** sort) must follow this pattern:

1. **Second-to-last:** 1 wrong (in either Chem or Phy), AIR 1, State 1, Batch 1, Branch 1
2. **Last:**           1 wrong (in the OTHER subject — Chem if #17 was Phy, Phy if #17 was Chem), AIR 2, State 1, Batch 1, Branch 1

This ensures the user always has an "almost topped" pair at the very bottom.

## Time distribution (always)

Total = 180 min (3 hours), split:
- **Mathematics: 70 min** (most)
- **Physics: 60 min**
- **Chemistry: 50 min** (least)

## Sort order

Tests are sorted **newest first** (most recent test on top of the list as displayed in the home screen).

## Tests shown vs hidden

- **All tests visible** except Olympiads (IOQM-*).
- Currently 17 visible tests + olympiads hidden.

## UI buttons

- Every card shows **"View Analysis"** button — no "Start Test" buttons anywhere.

## Comparative Analysis (per test, on analysis screen)

Subject-wise grouped bars (3 bars per subject: Topper, Me, Average):

- **Topper:** if me is full marks in that subject → same as me; else → me + 1 (capped at total)
- **Me:** my actual subject score
- **Average:** ~55% of subject total, rounded

Legend colors:
- Topper → blue (#1FA9E8)
- You    → orange (#F5A65B)
- Average → grey (#B0B0B0)
